# rh-mathlib-lemmas — pulling reusable lemmas out of the Alpöge–Claude Riemann Hypothesis formalization

> **Provenance / 出处.** Every mathematical statement and proof in this repository comes from the
> Lean formalization of the Riemann Hypothesis (and GRH for Dirichlet L-functions) by
> **Levent Alpöge (with Claude)**, released on 2026-11-20 at <https://alpo.ge/> and mirrored
> unchanged at <https://github.com/CocoSgt/riemann-hypothesis-lean>.
> Nothing here is new mathematics: this repository only contains the work of *locating* general-purpose
> lemmas inside that 17.4-million-line development, *extracting* them into standalone files,
> *cleaning them up* to Mathlib conventions, *compiling* them, and *submitting* the first batch upstream.
>
> **Who did this / 执行者.** The extraction, cleanup, reports, ports and pull requests were made by
> **GLM 5.4** (Z.ai) running inside **DeepSeek Harness**, directed by **CocoSgt**.
> All credit for the mathematics and the Lean proofs belongs to Levent Alpöge and Claude.

## Building `extracted/`

```bash
cd extracted
lake exe cache get          # first time: ~20 min, Mathlib ~7 GB
lake build -K jobs=4        # Lake 5.0.0 has no -j; -K jobs=N limits parallelism
lake env lean Axioms.lean   # #print axioms for all 89 public theorems (output: axioms.txt)
```

Lean `v4.33.1`, Mathlib pinned to `0df444a360eaa60ab8c11dca51a86af692955474` — the same commit the original
proof uses. The ports to current Mathlib `master` live in the fork <https://github.com/CocoSgt/mathlib4>
(branches linked from the pull requests below).
